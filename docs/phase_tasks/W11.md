Implement these twelve scenarios as separate, individually named tests:
 1. "hello" -> mention recognized, ZERO provider calls, ZERO ingestion, an LLM
    conversational response.
 2. "what research topics do I prefer?" with a seeded fake user graph
    (medical AI, world models) -> user memory used, ZERO provider calls, and
    the response contains no fabricated paper citation.
 3. New topic with an empty SQLite corpus and fakes that return new papers ->
    live discovery runs, canonical dedup, papers persisted to SQLite, response
    paper_ids are all resolvable in SQLite, and NO Project or WatchTopic had to
    exist first.
 4. The same query again -> no duplicate canonical papers in SQLite (assert the
    row count is unchanged), stored results reused.
 5. User memory backend unavailable (FakeUserMemoryStore(fail=True)) ->
    research chat still succeeds, used_user_memory is False.
 6. Semantic index unavailable -> lexical retrieval and live discovery still
    work.
 7. LLM unavailable -> no hallucinated answer text, degraded=True, and
    ZERO episodes written to the memory store.
 8. Guild message without a bot mention -> zero response, zero LLM calls, zero
    provider calls, zero memory writes.
 9. Message authored by another bot -> ignored.
10. Message containing an obvious (fake) API secret -> no episode written; the
    secret substring appears in no captured episode, no log record (use caplog),
    and no exception text.
11. Seeded user memory "I think method X is novel" with a corpus that does not
    support it -> assert the assembled prompt places that text under the USER
    MEMORY advisory section and never under a scientific-evidence section, and
    that the response does not present it as a literature finding.
12. A SQLite project with an explicit rejected_ideas entry that contradicts an
    older Graphiti memory fact -> assert the prompt marks the project state as
    canonical and outranking, per PHASE_CONTRACTS section 9.
