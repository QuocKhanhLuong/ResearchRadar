and FakeUserMemoryStore.

FakeUserMemoryStore is production-quality test infrastructure shipped in src so
smoke scripts can import it. Requirements:
- Constructor accepts seeded facts and a `fail: bool = False` flag.
- With fail=True every method behaves like a total backend outage: search
  returns [], get_context returns UserMemoryContext(backend=..., degraded=True,
  facts=()), add_episode returns False, status returns healthy=False. Nothing
  raises.
- Records every accepted episode so tests can assert what was and was not
  written (expose a read-only `episodes` property).
- search() does deterministic case-insensitive token overlap ranking so tests
  are stable.
- Supports temporal facts: a fact with invalid_at set in the past is excluded
  from the default search, but reachable via an explicit
  `include_historical=True` keyword on search().

__init__.py re-exports the public names so callers write
`from research_radar.memory import UserMemoryStore, MemoryClass, ...`.

Tests must cover: the disabled store never raises and never reports enabled;
the fake store's outage mode; temporal exclusion of invalidated facts;
UserMemoryContext.available; and that MemoryStatus carries no secret-shaped
content (assert `detail` is empty or a short fixed string).
