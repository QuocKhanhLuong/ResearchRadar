Requirements:
- ALL graphiti_core / kuzu imports are lazy and confined to this module, inside
  the methods or a private _ensure_client() helper. Importing
  research_radar.memory must never require graphiti-core to be installed.
- ImportError, driver construction failure, or any backend exception degrades:
  log ONE sanitized warning per failure class (use a flag so a repeated failure
  does not spam), then behave exactly like an outage — search returns [],
  get_context returns degraded context, add_episode returns False, status
  returns healthy=False. Never raise to the caller. No retry storms: do not
  retry inside a call; a failed initialization marks the store degraded until
  the process restarts.
- Suppress the Kuzu DeprecationWarning at the adapter boundary with a narrowly
  scoped warnings.catch_warnings/simplefilter around the driver construction
  only, and leave a comment explaining the deprecation and the escape hatch.
- Persistence path comes from settings.user_memory_db_path (resolved). The
  parent directory is created lazily on first write, not at import.
- group_id comes from settings.user_memory_group_id so all facts are scoped to
  the single user.
- LLM client and embedder reuse the repo's existing LLM/embedding configuration
  (OpenAI-compatible base_url + model + api key from Settings). Do NOT
  introduce duplicate provider env vars.
- Anything blocking must not run on the event loop. Graphiti's API is async, so
  await it directly; but any synchronous driver construction, filesystem work,
  or index build goes through asyncio.to_thread.
- Initialization (driver + build_indices_and_constraints) happens lazily on
  first use, exactly once, guarded by an asyncio.Lock so concurrent chat turns
  cannot double-initialize.
- close() is idempotent and safe to call when initialization never happened.
- Map returned edges to MemoryFact, carrying fact text, valid_at, invalid_at,
  and score when the API provides them. Exclude facts invalidated before now
  from the default search; keep the historical ones reachable so temporal
  evolution is preserved (August "prefers local embeddings" vs October "hosted
  embeddings are acceptable" must not collapse into one ahistorical fact).
- Use custom entity types keyed to MemoryClass IF and ONLY IF the spike
  confirms 0.29.x supports them; otherwise pass the class through the episode's
  source_description and record the deviation in a module docstring note.
- status() returns a safe MemoryStatus: backend name, enabled, healthy, a short
  fixed detail string, and the persistence path. NEVER include credentials,
  raw graph internals, or exception text that could echo episode content.
